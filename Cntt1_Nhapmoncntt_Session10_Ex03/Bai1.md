# Phần 1. Phân tích bài toán Giải thích tại sao Markdown lại giúp AI xử lý nhanh hơn dựa trên cơ chế chia nhỏ Token.
- Markdown giúp AI xử lí nhanh hơn vì lượng token cần dùng ít chia nhỏ code ra từng phần giúp cho AI dễ hiểu hơn và việc dùng ít token còn giúp cho AI chạy nhanh hơn và mượt hơn.
